# 하루 파이썬

종이 학습지처럼 읽고 기록하면서 옆의 코드 창에서 Python을 실행하는 데이터 분석 입문용 웹 학습 자료입니다.

## 1~5주차 학습 구성

| 일차 | 주제 | 학습 목표 |
| --- | --- | --- |
| 1일 | 첫 번째 코드 실행 | 출력하고, 수정하고, 다시 실행하기 |
| 2일 | 숫자로 계산하기 | 사칙연산과 괄호로 계산 순서 정하기 |
| 3일 | 값에 이름 붙이기 | 변수, 대입, 순서와 재계산 이해하기 |
| 4일 | 문자와 숫자 구별하기 | 자료형 확인과 문자열의 정수 변환 |
| 5일 | 나의 하루 지출 정리 | 예산·지출·잔액을 계산하고 해석하기 |
| 6일 | 여러 값을 리스트에 담기 | 리스트의 개수·합계·평균 |
| 7일 | 인덱스와 슬라이싱 | 특정 값과 구간 선택 |
| 8일 | 조건에 따라 판단하기 | 비교와 if·else, 경계값 확인 |

| 11일 | 딕셔너리로 기록 묶기 | 키와 값, 조회·수정·추가 |

| 15일 | 표 데이터 첫 분석 | 파일 구조 확인, 요약, 조건별 기록 수 |

| 18일 | 자료형 변환과 새 열 만들기 | 숫자 변환, 단위 변환과 파생 열 |
| 19일 | 그룹별 집계와 정렬 | 범주별 합계와 평균, 순서 정하기 |

| 21일 | 막대그래프로 크기 비교하기 | Matplotlib과 그래프 기본 구조 |

| 24일 | 읽기 쉬운 그래프 만들기 | 가로 막대, 축·단위·기준선 |

하루 30~40분, 일차별 3쪽(총 75쪽)입니다. 설명, 실행 예제, 예상 결과, 변형 실습, 독립 문제, 단계별 힌트, 정답·해설, 스터디 활동과 자기 점검을 포함합니다. 26~30일 차는 아직 제공하지 않습니다.

## 기능

- 주차·학습일 선택과 일차별 코드·답안·완료 상태의 브라우저 내 저장
- 기존 1일 차 저장 기록 유지
- Pyodide 기반 실제 Python 실행, 중지, 오류별 한국어 안내
- 코드에서 사용하는 pandas·Matplotlib 자동 로딩
- plt.show() 그래프 출력과 PNG 다운로드(실행당 최대 8개)
- 14~20일·25일 차 공부·독서·지출 예제 CSV 자동 준비 및 다운로드
- 모바일 주차·학습일 선택과 반응형 레이아웃
- 현재 학습일 전체 인쇄: 답안과 펼친 힌트·해설 포함

공동 편집이나 계정 간 동기화는 제공하지 않습니다. 실행 시 필요한 변수는 같은 입력 칸에 작성하세요. 실행마다 새 Python 전역 이름 공간에서 시작합니다.

## 실행

빌드 과정 없이 정적 웹 서버에서 실행합니다.

```sh
python -m http.server 8000
```

브라우저에서 http://localhost:8000 을 엽니다. file:// 방식 대신 HTTP 서버를 사용하세요. 첫 실행 시 CDN에서 Python 환경을 내려받으므로 인터넷 연결이 필요합니다.

## 파일

- `index.html`: 화면 구조
- `style.css`: 학습지·실습 창·반응형·인쇄 스타일
- `lessons.js`: 1~25일 차 본문, 예제, 예상 결과와 정답
- `app.js`: 날짜 이동, 편집기, 로컬 저장, 실습과 인쇄 제어
- `worker.js`: 별도 Worker의 Python 실행, 패키지 로딩, 예제 CSV 준비
- `data/study_week.csv`: 가상 월~금 공부 기록(분)
- `data/reading_week.csv`: 가상 월~금 독서 기록(분)
- `data/spending_week.csv`: 가상 지출 8건(원)
- `data/spending_raw.csv`: 중복·결측·비숫자 값이 있는 가상 지출 11행(원)

## 검증 현황

- JavaScript 문법 검사
- 예제·정답 75개를 Pyodide에서 실제 실행해 예상 출력과 대조(pandas·Matplotlib 및 네 CSV 포함)
- 실제 Worker 코드로 그래프 15개 생성, 오류 이후 그림 정리 및 재실행 확인
- 주요 그래프의 PNG 이미지에서 제목·축·단위 시각 검수
- DOM 기반으로 75쪽 탐색, 예제 불러오기, 기존 기록 유지, 날짜별 저장, 완료 체크, 인쇄용 문서와 모바일 선택기 동작 확인

실제 브라우저의 시각적 레이아웃과 인쇄 출력의 통합 검증은 아직 진행하지 않았습니다.

## 예제 데이터

네 CSV는 교육용 가상 데이터입니다. 공부·독서 자료는 한 사람의 월~금 하루 한 기록이며 시간 단위는 분입니다. 지출 자료는 한 행이 한 거래이며 단위는 원입니다. 원본 지출 자료에는 확인된 중복 1건과 금액을 알 수 없는 기록 2건이 포함됩니다. 정리 후 합계는 금액이 알려진 8건에 대한 값입니다. 웹 실습에서는 해당 학습일의 파일이 자동으로 준비됩니다. 직접 Python에서 실행하려면 CSV를 현재 작업 폴더에 복사하거나 `pd.read_csv("data/study_week.csv")`처럼 경로를 지정하세요.

현재 페이지의 학습 코드와 답안은 브라우저에 저장되지만, Python 가상 파일 시스템은 영구 저장소가 아닙니다. 제공 CSV는 실행 시 원본으로 복원됩니다.

## 그래프 실습

21~25일 차는 Matplotlib을 사용합니다. 그래프의 제목과 축에는 기본 글꼴로 표시 가능한 영문을 사용하고, 한글 해설에서 뜻과 단위를 설명합니다. 한글 글꼴은 별도로 제공하지 않습니다. `plt.show()`는 열린 그림을 실습 창으로 내보내고 닫습니다. 그림은 자동 저장되지 않으며 PNG 받기로 저장할 수 있습니다. 다시 실행하거나 다른 날짜·예제를 선택하면 이전 그림은 지워집니다. 학습지 인쇄에는 본문·답안·해설이 포함되며 실행한 그래프는 PNG로 따로 보관합니다.
