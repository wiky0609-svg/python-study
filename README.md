# 하루 파이썬

종이 학습지처럼 읽고 기록하면서, 옆의 코드 창에서 Python을 실행하는 데이터 분석 입문용 웹 학습 자료.

## 현재 구현

- 1일 차 학습지 3쪽: 따라 하기, 바꿔 보기, 독립 문제와 자기 점검
- Pyodide 기반 실제 Python 실행, 실행 중지, 오류 안내
- 단계별 힌트와 해설
- 답안·코드·학습 체크의 브라우저 내 저장
- 학습지 인쇄와 모바일 레이아웃

2일 차 이후 콘텐츠는 준비 중입니다. 공동 편집과 계정 간 진도 동기화는 제공하지 않습니다.

## 실행

별도 빌드 과정 없이 정적 웹 서버에서 실행합니다.

```sh
python -m http.server 8000
```

브라우저에서 http://localhost:8000 을 엽니다. 파일을 직접 여는 file:// 방식 대신 HTTP 서버를 사용하세요.

첫 실행 시 CDN에서 Python 실행 환경을 내려받으므로 인터넷 연결이 필요합니다. 각 실행은 새 Python 전역 이름 공간에서 진행됩니다.

## 파일

- `index.html`: 화면 구조
- `style.css`: 학습지, 실습 창, 반응형 및 인쇄 스타일
- `app.js`: 학습 내용, 편집기, 로컬 저장, 실습 제어
- `worker.js`: 별도 Worker에서 Python 실행

## 검증 현황

JavaScript 문법, 로컬 파일 참조, 학습 예제 계산 결과를 확인했습니다. 실제 브라우저 화면·Python 실행·인쇄 결과의 통합 검증은 아직 진행하지 않았습니다.
